## 相空间解析模型 / Phase Space Analysis Model

本仓库新增了完整的相空间分析工具，用于分析动力学系统的相空间行为。这对于理解常微分方程的解的行为特别有用。

This repository now includes a complete phase space analysis toolkit for analyzing the phase space behavior of dynamical systems. This is particularly useful for understanding the behavior of ordinary differential equation solutions.

### 快速开始 / Quick Start

```matlab
% 运行快速入门教程
phase_space_quickstart

% 查看完整示例集
phase_space_examples
```

### 文件说明 / Files

- **`phase_space_analysis.m`** - 主要的相空间分析函数 / Main phase space analysis function
- **`phase_space_quickstart.m`** - 快速入门教程 / Quick start tutorial
- **`phase_space_examples.m`** - 完整示例集（5个经典系统）/ Complete examples (5 classical systems)
- **`PHASE_SPACE_README.md`** - 详细文档 / Detailed documentation
